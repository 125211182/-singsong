# 智声评 - AI 智能声乐评测系统

> 面向音乐课堂的智能声乐评测工具：让学生的演唱过程可视化，让教师的课堂评价更有依据。

智声评是一款面向音乐教育场景的 AI 声乐评测应用。它可以在学生演唱过程中实时检测音高轨迹，并在演唱结束后生成音准、节奏、情绪三个维度的评分与评价，帮助教师更直观地观察学生的演唱表现。

这个项目更适合被理解为音乐课堂里的“观察工具”：它不替代音乐教师的专业判断，而是帮助教师看见学生唱得哪里准、哪里不稳、哪里值得继续练习。

## 核心亮点

- 实时旋律线展示：学生演唱时，可以看到自己的音高变化轨迹。
- 多维度智能评分：从音准、节奏、情绪三个维度生成综合评价。
- 演唱画像分析：对比标准旋律与学生演唱轨迹，直观看到偏差位置。
- 乐谱同步展示：支持上传乐谱图片，方便教师在课堂中同步对照歌曲内容。
- 课堂记录管理：支持多名学生评测记录，便于课堂展示与课后回顾。
- 一键分享课堂：生成课堂数据分享链接，便于学生复盘和教师留痕。

## 应用界面

智声评主要分为四个区域：

1. 学生评价部分
   - 展示学生总分、等级、音准、节奏、情绪分项评分。
   - 自动生成面向课堂反馈的演唱建议。
   - 支持查看乐句得分明细，帮助教师定位具体问题。

2. 演唱旋律线展示部分
   - 学生演唱过程中实时显示音高轨迹。
   - 教师可以直观看到学生声音的高低变化和稳定性。
   - 适合用于课堂即时反馈和演唱过程观察。

3. 乐谱展示部分
   - 支持上传乐谱图片。
   - 课堂中可以同步查看歌曲旋律、歌词和演唱内容。
   - 适合配合教材歌曲、课堂练唱和分句指导使用。

4. 学情画像展示部分
   - 演唱结束后生成“标准旋律 vs 学生演唱轨迹”的对比图。
   - 蓝色线条表示标准旋律。
   - 绿色点表示命中标准音的演唱位置。
   - 红色点表示偏离标准音的演唱位置。
   - 支持横向滚动查看较长歌曲的完整轨迹。

## 评分维度

| 维度 | 权重 | 说明 |
| --- | --- | --- |
| 音准 | 50% | 根据学生演唱音高与标准旋律的差异进行评估 |
| 节奏 | 30% | 关注演唱完成度、节奏覆盖率和时间准确性 |
| 情绪 | 20% | 根据声音稳定性、音量动态和表现状态进行分析 |

## 适用场景

- 音乐课堂中的学生演唱测评
- 歌唱教学中的音准与节奏反馈
- 合唱排练中的个人表现记录
- 课后练习与学生自我复盘
- 音乐教师课堂评价数据留痕

## 使用流程

1. 准备素材
   - 上传范唱干声。
   - 可选上传伴奏音频。
   - 可选上传乐谱图片。

2. 开始评测
   - 点击开始评测。
   - 授权浏览器麦克风权限。
   - 学生开始演唱，系统实时检测音高。

3. 查看反馈
   - 演唱结束后，系统生成综合评分。
   - 左侧课堂记录显示学生成绩和评价。
   - 右侧演唱画像展示学生演唱轨迹与标准旋律的差异。

4. 分享课堂
   - 点击分享课堂生成链接。
   - 可用于课后复盘、学生练习和教师留痕。

## 项目价值

在传统音乐课堂中，教师往往需要凭经验快速判断学生的音准、节奏和表现状态。智声评希望把这部分过程变得更可见：

- 对学生来说，可以看见自己的声音轨迹。
- 对教师来说，可以获得更直观的课堂观察依据。
- 对课堂来说，可以把一次演唱变成可回看、可分析、可改进的学习过程。
