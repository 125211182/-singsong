# UI 全面升级计划

## 概述

对「智声评」智能声乐评测应用进行 UI 全面升级，目标平台为 **Web**。升级涵盖视觉设计、交互体验、可访问性和响应式适配四大维度，采用深色主题 + 霓虹点缀的专业音乐教育风格。

## 非破坏性迁移策略

**核心原则**：渐进式升级，确保现有功能零中断

| 策略 | 说明 |
|------|------|
| **功能保留** | 所有现有功能（音频上传、实时检测、评分算法、分享）保持不变 |
| **渐进替换** | 按模块逐步升级，每次只改一个组件，确保可回滚 |
| **样式隔离** | 新样式使用独立类名，避免覆盖现有样式 |
| **状态兼容** | 组件状态管理逻辑不变，仅升级视觉层 |
| **回退机制** | 保留旧样式作为 fallback，新样式失败时自动降级 |

**迁移顺序**：
1. 先升级样式变量（颜色、字体）→ 视觉变化，功能不变
2. 再替换图标（emoji → SVG）→ 视觉变化，功能不变
3. 最后添加动画 → 增强体验，功能不变

## 技术方案

| 维度 | 选择 | 理由 |
|------|------|------|
| 图标库 | Lucide React | 专业 SVG 图标，替代 emoji |
| 动画库 | Framer Motion | 流畅的过渡动画 |
| 颜色系统 | 深色 OLED 优化 | 深黑 #0F0F1A + 霓虹点缀 |
| 字体 | Poppins + 思源黑体 | 现代感 + 中文优化 |
| 组件规范 | shadcn/ui | 保持一致性 |

## 功能模块

### 1. 图标系统升级
- 替换所有 emoji 为 Lucide SVG 图标
- 统一图标尺寸（16px/20px/24px）
- 添加图标悬停效果

### 2. 颜色系统重构
| 变量 | 当前值 | 新值 | 用途 |
|------|--------|------|------|
| --background | #121214 | #0F0F1A | 主背景 |
| --panel | #1e1e20 | #1A1A2E | 面板背景 |
| --primary | #0a84ff | #6366F1 | 主色调（靛蓝） |
| --success | #30d158 | #22C55E | 成功色 |
| --danger | #ff453a | #EF4444 | 危险色 |
| --accent | - | #F59E0B | 强调色（琥珀） |

### 3. 动画与过渡
- 页面切换：300ms ease-out
- 按钮悬停：150ms scale(1.02)
- 卡片进入：stagger 动画
- 分数变化：数字滚动效果

### 4. 可访问性增强
- 所有可点击元素添加 cursor-pointer
- 焦点状态可见（focus-visible）
- 颜色对比度 ≥ 4.5:1
- 添加 aria-label
- 支持 prefers-reduced-motion

### 5. 响应式优化
- 桌面端：三栏布局（320px + flex + 600px）
- 移动端：标签页切换（主控台/课堂记录/乐谱视窗）
- 平板端：自适应缩放

### @page(/) 主控台

**核心职责**：声乐评测的核心交互界面，支持音频上传、实时演唱、旋律可视化和评分展示。

**布局**：
- 顶部：标题栏（Logo + 应用名）
- 桌面端三栏：左侧课堂记录 | 中间主控台 | 右侧乐谱视窗
- 移动端：底部标签页切换

**区块组成**：
1. **上传区域**：干声/伴奏/乐谱文件上传
2. **旋律可视化**：Canvas 实时绘制音高曲线
3. **控制按钮**：开始演唱/暂停/停止
4. **实时分数**：音准/节奏/情绪实时显示
5. **学生卡片**：评分结果展示

**交互说明**

| 元素 | 动作 | 响应 | 备注 |
|------|------|------|------|
| Logo | 点击 | 无操作 | 品牌标识 |
| 上传槽位 | 点击 | 打开文件选择器 | 支持拖拽 |
| 开始演唱按钮 | 点击 | 启动录音+播放伴奏 | 主色调高亮 |
| 暂停/继续按钮 | 点击 | 暂停/恢复播放 | 仅演唱中可见 |
| 停止按钮 | 点击 | 结束演唱，计算评分 | 仅演唱中可见 |
| 学生卡片 | 点击 | 展开详细评语 | 可折叠 |
| 分享按钮 | 点击 | 生成分享链接 | 显示 Toast |
| 移动端标签 | 点击 | 切换视图 | 底部固定 |

### 移动端标签页

- 🎹 主控台（默认）

- 🎼 乐谱视窗
